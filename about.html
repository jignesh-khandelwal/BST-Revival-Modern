About the Project

Discover the purpose, features and educational goals of Binary Tree Visualiser.

Project Overview

Binary Tree Visualiser is an interactive educational application designed to help learners understand binary tree data structures and the algorithms that operate on them. It presents tree operations visually, making their behaviour easier to follow.

Binary Search Tree

Explore how a Binary Search Tree works through operations such as:

  • Inserting and searching for nodes.
  • Deleting nodes.
  • Finding minimum and maximum values.
  • Performing Inorder, Preorder and Postorder traversals.

Binary Heap

Understand binary heap operations and how heaps support priority queue concepts through visual demonstrations.

Learning Through Visualisation

The application combines animated operations, step-by-step execution, playback controls, instructions and pseudocode to help learners understand how algorithms work.

Project Evolution

This revival modernises the original application with a responsive interface and an updated graphics-rendering approach, while aiming to preserve its original algorithms and educational purpose.
