1. Binary Tree

A binary tree is a hierarchical data structure in which each node contains a value and can have at most two children: a left child and a right child. The first node is the root. A node with no children is called a leaf.

  • Root: The topmost node.
  • Parent: A node directly above another node.
  • Child: A node directly below another node.
  • Leaf: A node without children.
  • Subtree: A node together with its descendants.

A node can be represented recursively:

class BinaryTreeNode {
    constructor(value) {
        this.value = value;
        this.parent = null;
        this.left = null;
        this.right = null;
    }
}

The application's BinaryTree structure provides operations such as getRoot(), setRoot(), getCount(), build(), swapNodes(), getNode() and getIndex().

A tree traversal visits every node once: O(n) time.

2. Binary Heap — Max Heap

A binary heap is a complete binary tree. Every level is full except possibly the last, and nodes on the last level are filled from left to right.

This application implements a Max Heap. Every parent has a value greater than or equal to the values of its children. Therefore, the maximum value is always at the root.

A heap is commonly used to implement a priority queue, where the highest-priority (largest) value is retrieved first.

  • Get Max: inspect the root.
  • Insert: add at the next available position, then heapify up.
  • Extract Max: remove the root, move the last node to the root, then heapify down.

For a zero-based array representation, the children of index i are at 2i + 1 and 2i + 2; the parent is at floor((i - 1) / 2).

3. Heapify Down

Heapify Down restores the Max Heap property when a node may be smaller than one of its children. It repeatedly swaps the node with its larger child until the property is restored. 

function heapifyDown(node) {
    while (node has at least one child) {
        greaterChild = the child with the greater value

        if (node.value >= greaterChild.value) {
            return
        }

        swap(node, greaterChild)
        node = greaterChild
    }
}

Time: O(log n) in the worst case. Space: O(1) for this iterative version.

4. Heapify Up

Heapify Up restores the Max Heap property after inserting a new node. It compares the node with its parent and swaps them while the node is greater than its parent. 

function heapifyUp(node) {
    while (node has a parent) {
        parent = node.parent

        if (parent.value >= node.value) {
            return
        }

        swap(node, parent)
        node = parent
    }
}

Time: O(log n) in the worst case. Space: O(1) for this iterative version.

5. Random Binary Heap

The application generates a random collection of distinct values within the supplied minimum and maximum range. It then builds a valid Max Heap. This is an application-specific generator, not a general random-tree algorithm. 

function randomBinaryHeap(min, max) {
    count = random integer from 1 to
            min(max - min + 1, 31)

    values = generate count unique random integers
             between min and max

    buildHeap(values)
}

Generating unique values depends on the generation method. Building the heap takes O(n) time.

6. Build Heap

Build Heap converts an array into a valid Max Heap. It starts from the last non-leaf node and applies Heapify Down towards the root. 

function buildHeap(array) {
    tree = build complete binary tree from array

    start = floor(array.length / 2) - 1

    for (i = start; i >= 0; i--) {
        heapifyDown(tree.getNode(i))
    }

    return tree
}

Time: O(n), not O(n log n). Space: O(1) auxiliary space when the existing tree is rearranged in place.

7. Heap Insert

A new node is placed at the next available position to preserve the complete-tree structure. Heapify Up then restores the Max Heap property. 

function insertHeap(tree, value) {
    node = new BinaryTreeNode(value)

    if (tree is empty) {
        tree.setRoot(node)
        return node
    }

    index = tree.getCount()
    parentIndex = floor((index - 1) / 2)
    parent = tree.getNode(parentIndex)

    if (index is odd) {
        parent.setLeft(node)
    } else {
        parent.setRight(node)
    }

    heapifyUp(node)
    return node
}

Time: O(log n). The new node is inserted at the next complete-tree position.

8. Heap Delete

The application allows deletion of a selected heap node. The last node is moved into the selected node's position, and the heap property is restored by moving the replacement up or down as necessary. 

function deleteHeapNode(tree, target) {
    last = tree.getNode(tree.getCount() - 1)

    if (target is last) {
        detach last from its parent
        return
    }

    swap target and last
    detach last from its parent

    heapifyUp(target)
    heapifyDown(target)
}

Time: O(log n). The exact replacement node and its position must be maintained when swapping nodes in a linked tree.

9. Get Max

The maximum value in a Max Heap is always stored at the root. Get Max returns that node without removing it. 

function getMaxHeap(tree) {
    return tree.getRoot()
}

Time: O(1).

10. Extract Max

Extract Max returns and removes the root node. The last node replaces the root, and Heapify Down restores the Max Heap property. 

function extractMax(tree) {
    maximum = tree.getRoot()

    if (maximum is null) {
        return null
    }

    deleteHeapNode(tree, maximum)
    return maximum
}

Time: O(log n).

11. Heap Sort

This application's Heap Sort repeatedly extracts the maximum value. The extracted values are collected and reversed to produce ascending order. 

function heapSort(tree) {
    result = []

    while (tree is not empty) {
        result.push(extractMax(tree).value)
    }

    reverse(result)
    return result
}

Time: O(n log n). The application performs repeated extraction and returns an ascending array.

12. Binary Search Tree (BST)

A Binary Search Tree is a binary tree organised by value. In this application, values smaller than a node go into its left subtree, while values greater than or equal to the node go into its right subtree. Both subtrees must follow the same rule.

Duplicate values are therefore inserted into the right subtree.

13. Random Binary Search Tree

The application uses a custom random generator. It chooses a root value and recursively generates left and right children within ranges that preserve the BST ordering property. The generation probability decreases at deeper levels to limit tree size and shape. 

function randomBST(min, max) {
    rootValue = random integer within a safe inner range
    root = new BinaryTreeNode(rootValue)

    generateChildren(root, 1, min, max)
    return root
}

function generateChildren(node, level, min, max) {
    if (range is too small or safety limit reached) {
        return
    }

    chance = probability based on level

    if (random chance succeeds) {
        leftValue = random integer less than node.value
        node.left = new BinaryTreeNode(leftValue)
        generateChildren(node.left, level + 1,
                         min, node.value - 1)
    }

    if (random chance succeeds) {
        rightValue = random integer greater than or equal to node.value
        node.right = new BinaryTreeNode(rightValue)
        generateChildren(node.right, level + 1,
                         node.value + 1, max)
    }
}

This is a custom visualisation generator; it does not guarantee a uniformly random BST shape.

14. BST Insert

Start at the root and compare the new value with each visited node. Move left for a smaller value and right for a greater or equal value. Insert when the appropriate child position is empty. 

function insertBST(tree, value) {
    newNode = new BinaryTreeNode(value)

    if (tree.getRoot() is null) {
        tree.setRoot(newNode)
        return newNode
    }

    current = tree.getRoot()

    while (true) {
        if (value >= current.value) {
            if (current.right is null) {
                current.setRight(newNode)
                return newNode
            }
            current = current.right
        } else {
            if (current.left is null) {
                current.setLeft(newNode)
                return newNode
            }
            current = current.left
        }
    }
}

Average time: O(log n) for a reasonably balanced tree. Worst case: O(n) for a skewed tree.

15. Find

Find compares the requested value with the current node. It returns the first matching node encountered, or null if the search reaches an empty child position. 

function find(tree, value) {
    current = tree.getRoot()

    while (current is not null) {
        if (current.value == value) {
            return current
        }

        if (value >= current.value) {
            current = current.right
        } else {
            current = current.left
        }
    }

    return null
}

Average time: O(log n). Worst case: O(n).

16. BST Delete

There are three main deletion cases:

  1. No children: Disconnect the node from its parent. If it is the root, make the tree empty.
  2. One child: Connect the node's only child directly to its parent. If it is the root, make the child the new root.
  3. Two children: Find the inorder successor (the minimum node in the right subtree), exchange its position with the target, then remove the successor.
function deleteBST(tree, node) {
    if (node has both children) {
        successor = getSuccessor(node)
        swapPositions(node, successor)
    }

    // The target now has at most one child.
    child = node.left if it exists, otherwise node.right

    if (node is the root) {
        tree.setRoot(child)
    } else if (node is the left child of its parent) {
        node.parent.setLeft(child)
    } else {
        node.parent.setRight(child)
    }

    if (child is not null) {
        child.parent = node.parent
    }
}

This is a conceptual outline. The application's swapNodes operation exchanges node positions and maintains parent/child relationships before the final removal.

Average time: O(log n). Worst case: O(n).

17. BST Get Max

The maximum value is found by following right-child links until no right child remains. The method can operate on a selected subtree. 

function getMax(root) {
    if (root is null) {
        return null
    }

    current = root

    while (current.right is not null) {
        current = current.right
    }

    return current
}

Time: O(h), where h is the tree height.

18. BST Get Min

The minimum value is found by following left-child links until no left child remains. 

function getMin(root) {
    if (root is null) {
        return null
    }

    current = root

    while (current.left is not null) {
        current = current.left
    }

    return current
}

Time: O(h), where h is the tree height.

19. BST Get Predecessor

The inorder predecessor is the node visited immediately before the given node during inorder traversal.

  1. If the node has a left subtree, its predecessor is the maximum node in that subtree.
  2. Otherwise, move up through ancestors until the current node is reached from its parent's right child. That parent is the predecessor.
function getPredecessor(node) {
    if (node.left is not null) {
        return getMax(node.left)
    }

    child = node
    parent = node.parent

    while (parent is not null) {
        if (parent.right == child) {
            return parent
        }

        child = parent
        parent = parent.parent
    }

    return null
}

Time: O(h).

20. BST Get Successor

The inorder successor is the node visited immediately after the given node during inorder traversal.

  1. If the node has a right subtree, its successor is the minimum node in that subtree.
  2. Otherwise, move up through ancestors until the current node is reached from its parent's left child. That parent is the successor.
function getSuccessor(node) {
    if (node.right is not null) {
        return getMin(node.right)
    }

    child = node
    parent = node.parent

    while (parent is not null) {
        if (parent.left == child) {
            return parent
        }

        child = parent
        parent = parent.parent
    }

    return null
}

Time: O(h).

21. Preorder Traversal

Preorder processes the current node first, then the left subtree, and finally the right subtree.

Order: Root → Left → Right

function preorder(node, result) {
    if (node is null) {
        return
    }

    result.push(node)
    preorder(node.left, result)
    preorder(node.right, result)
}

Time: O(n). Recursive space: O(h).

22. Inorder Traversal

Inorder processes the left subtree first, then the current node, and finally the right subtree. In a BST, this produces values in non-decreasing order.

Order: Left → Root → Right

function inorder(node, result) {
    if (node is null) {
        return
    }

    inorder(node.left, result)
    result.push(node)
    inorder(node.right, result)
}

Time: O(n). Recursive space: O(h).

23. Postorder Traversal

Postorder processes the left subtree, then the right subtree, and finally the current node.

Order: Left → Right → Root

function postorder(node, result) {
    if (node is null) {
        return
    }

    postorder(node.left, result)
    postorder(node.right, result)
    result.push(node)
}

Time: O(n). Recursive space: O(h).
