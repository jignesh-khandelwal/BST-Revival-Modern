Project Background

BinaryTreeVisualiser is a JavaScript educational application originally developed as a Bachelor's final project.

Modernisation Project

This revival preserves the educational purpose and original binary tree algorithms while modernising the website and improving responsive behaviour.

The original application used the open-source JavaScript Graphics Library (JSGL) for rendering. The modern version is planned to use a native SVG-based renderer after functional testing.
